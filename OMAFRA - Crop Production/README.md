# 🍇 OMAFRA Crop Production Dashboard

### A Tableau Dashboard for Analyzing Ontario’s Fruit and Crop Performance

---

## 🧩 Overview

This dashboard visualizes **Ontario’s agricultural production trends** using data from the **Ontario Ministry of Agriculture, Food and Agribusiness (OMAFRA)**.
It highlights **fruit and crop performance** across **counties, regions, and the provincial level** for Ontario from **1995 to 2024**, showcasing production volume, harvested area, and economic value.

The dataset provides insights into how **Ontario’s fruit industry** has evolved over three decades, enabling comparison across **geographies, crops, and years**.
Data is sourced from OMAFRA’s official crop production statistics (not Statistics Canada, but OMAFRA) and processed for spatial integration in Tableau using county-level shapefiles.

---

## 📑 Dashboard Pages

### **Page 1 – Crop Production Overview**

**Purpose:** Present an interactive visualization of Ontario’s fruit production and farm value metrics.

**Key Features:**

* KPI highlights for *Harvested Area*, *Marketed Production*, *Average Price*, and *Farm Value*
* Choropleth map of *Farm Value by County or Region*
* Dynamic insights showing *Top Performing County* per selected filters
* Interactive filters for *Geography Level*, *County/Region*, *Fruit Type*, and *Year Range*
* Derived metrics including *Yield per Acre* and *Farm Value per Acre*

**Goal:** Provide users with a clear, filter-driven exploration of how crop yields, prices, and farm values vary across Ontario’s agricultural regions.

**Data:** Downloaded from **OMAFRA’s Crop Production Statistics Portal**
