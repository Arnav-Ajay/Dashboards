# OpenAQ Air Monitoring Location Insights Dashboard 🌍

This Power BI dashboard is part of a larger environmental analytics project that combines data from OpenAQ and EPA sources to analyze air quality and develop predictive models.  
The dashboard provides an exploratory analysis view of station metadata and pollutant time series for February 2025 for station from OpenAQ only.

### 🔍 Dashboard Features
- Interactive filters for Country, Pollutant, Owner, Provider, and Date Range  
- Map view color-coded by station activity with bubble size representing average pollutant concentration  
- Drill-through to station-level pollutant trends and summary statistics

### 📊 Files
- **OpenAQ Location Insight.pbix** – Power BI file
- **OpenAQ Location Insight.pdf** – Exported static view of the dashboard

### 🌱 Part of:
**Air Quality Prediction Project** – a larger effort to model pollutant levels using meteorological and geospatial factors such as:
- Temperature, Relative Humidity, Wind Speed & Direction  
- Elevation and Proximity-based attributes  
- Station activity metadata and data source reliability
